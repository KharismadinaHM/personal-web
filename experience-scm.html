Pencocokan Otomatis Gen21 & Nielsen TV Ratings

Mengembangkan program pencocokan data periklanan berbasis event-driven dengan Python menggunakan teknik machine learning fuzzy wuzzy. Solusi ini berhasil mengintegrasikan dataset heterogeneous dari Gen21 (traffic log) dan Nielsen Media Research untuk analisis rating pemirsa siaran TV nasional (SCTV & Indosiar).

Meningkatkan akurasi pencocokan log iklan komersial hingga 90%.
Memangkas waktu komputasi pemrosesan harian sebesar 80% dibanding metode manual sebelumnya.

High-Level Architecture: Batch & Real-Time Data Matching

Geser diagram ke samping untuk melihat seluruhnya →

  1. Sumber data: data rating Nielsen tersimpan di MySQL, sedangkan traffic log iklan Gen21 tersimpan di SQL Server.
  2. Jalur batch (harian): DAG Apache Airflow mengekstrak data dari kedua database setiap hari lalu menjalankan program matching.
  3. Jalur real-time: Debezium menangkap setiap perubahan data (CDC) di kedua database dan mengalirkannya ke topik Apache Kafka, yang kemudian dikonsumsi oleh program matching.
  4. Program matching (Docker): aplikasi Python yang dikemas dalam container Docker mencocokkan record Nielsen dan Gen21 berdasarkan kemiripan string menggunakan fuzzywuzzy.
  5. Output: hasil matching dari kedua jalur dikirim ke PostgreSQL milik departemen Marketing untuk analisis rating dan penayangan iklan.

Pipeline Streaming Kafka + Spark + Docker

Membangun dan mengonfigurasi pipeline streaming data menggunakan kontainerisasi Docker, Apache Kafka sebagai message broker terdistribusi, Apache Spark untuk micro-batch processing cepat, dan MySQL sebagai storage hilir.

Mampu menangani peningkatan volume data hingga 40% tanpa latensi berlebih.
Menjamin keandalan pengiriman data (zero data loss) dan kontinuitas analitik waktu nyata.

Orkestrasi & Efisiensi Operasional dengan Airflow

Peningkatan keandalan job scheduler dan deteksi dini kegagalan pipeline.

Troubleshooting Kompleks & Otomasi DAGs

Mengimplementasikan Directed Acyclic Graphs (DAGs) terstandarisasi pada Apache Airflow untuk mengotomatiskan penanganan galat dan troubleshooting kesalahan sistem yang kompleks.

Mereduksi system downtime sebesar 35% melalui notifikasi kegagalan dan automatic retries.
Mencapai efisiensi operasional sistem sebesar 99.8% untuk seluruh batch job harian.
