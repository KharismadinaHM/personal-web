Machine Learning Use Case

Predictive Maintenance Spare Part Motor

Memprediksi kapan sebuah motor perlu penggantian spare part dan ganti oli, menggunakan data yang diekstraksi dari foto odometer dan plat nomor. Seluruh pipeline berjalan on-premise dengan Python.

Parameter model

  • Odometer — jarak tempuh motor (km) hasil ekstraksi dari foto odometer.
  • Pembaruan spare part — riwayat kapan dan pada kilometer berapa spare part terakhir diganti.
  • Lamanya ganti oli — rentang waktu sejak penggantian oli terakhir.

High-Level Architecture (On-Premise · Python)

Geser diagram ke samping untuk melihat seluruhnya →

  1. Input gambar: foto odometer dan plat nomor motor dikumpulkan dan disimpan di server on-premise.
  2. Ekstraksi gambar → tabular: program Python membaca angka odometer dan plat nomor dari gambar, lalu menyimpannya sebagai baris data tabular (plat nomor, odometer, tanggal).
  3. Penggabungan riwayat servis: data tabular digabungkan berdasarkan plat nomor dengan riwayat pembaruan spare part dan ganti oli.
  4. Feature engineering & model: odometer, jarak tempuh sejak spare part terakhir diganti, dan lamanya sejak ganti oli terakhir menjadi input model prediktif berbasis Python.
  5. Output: prediksi kebutuhan penggantian spare part dan ganti oli per motor, sebagai dasar penjadwalan maintenance.
